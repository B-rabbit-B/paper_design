# static/：前端静态资源

先读根目录 `CLAUDE.md`。

| 路径 | 内容 |
|---|---|
| `style.css` | 全站样式（约 1400 行，已超过 800 行建议值；阶段 3、4 改页面时可以按页面拆分，不单独为拆而拆） |
| `manifest.json`、`icons/` | PWA 清单与图标 |
| `sw.js` | Service Worker：缓存首页和静态资源以支持离线，缓存名 `nutrition-v1` |
| `uploads/` | 识别上传的原图和结果图，**不入库**（已 gitignore）。阶段 3 的识别接口才会写入，现在目录还不存在 |
| `vendor/` | 阶段 3、4 引入前端库时才创建（计划里有，现在没有） |

## 约定

- **改了 `style.css` 或 `sw.js` 缓存的资源后，把 `sw.js` 里的 `CACHE_NAME` 版本号加一**，否则浏览器会一直用旧缓存，你看到的页面和实际代码对不上。
- 前端库不要从外网 CDN 引用（答辩现场可能没网），放进 `vendor/` 并写明版本和许可。
- 不要把用户上传的图提交进仓库；截图类的验收证据放 `docs/acceptance/stage-N/`。
